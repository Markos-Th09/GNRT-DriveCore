## Αρχές Ανάπτυξης

Ο κώδικας ακολουθεί τις παρακάτω αρχές:

- Καθαρός και τεκμηριωμένος κώδικας.
- Modular σχεδίαση.
- Επαναχρησιμοποίηση κλάσεων.
- Απλότητα στη χρήση.
- Συμβατότητα με το επίσημο FTC SDK.

---

## Μελλοντικές Προσθήκες

- Odometry
- Pure Pursuit
- Trajectory Following
- Autonomous Motion
- Motion Profiling
- Vision Integration
- AprilTag Localization

---

## Συνεισφορά

Οι αλλαγές πραγματοποιούνται μέσω Pull Requests.

Κάθε νέα λειτουργία θα πρέπει να:

- ακολουθεί τα πρότυπα κώδικα της ομάδας,
- συνοδεύεται από τεκμηρίωση,
- περιλαμβάνει παραδείγματα χρήσης όπου απαιτείται.

---

## Άδεια Χρήσης

Το έργο αναπτύσσεται αποκλειστικά για την **Εθνική Ομάδα Ρομποτικής FIRST Global Ελλάδας**.
